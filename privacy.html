Ren privacy policy

Last updated: 7 October 2026

Who uses Ren

Ren is a personal assistant used by one person, its owner, on their own computer. There are no other users and no public service.

Google data Ren accesses

  • Google Calendar: lists the owner's calendars and events, and creates or updates events in the owner's own calendars. Ren never adds guests or sends invitations.
  • Gmail: reads the owner's messages so the owner can ask about them, and sends a message only after the owner has approved that exact message.
  • Google Drive: reads the owner's files so the owner can ask about them, and creates files that Ren itself made (for example a document the owner asked for). Ren does not delete or share the owner's files.

How the data is used and stored

  • Google data is processed on the owner's own PC to answer the owner's requests. It is not sold, shared with third parties, used for advertising, or used to train AI models.
  • Sign-in tokens are stored only on the owner's PC in a folder restricted to the owner's Windows account.
  • Email and file contents are not copied into Ren's long-term memory unless the owner asks.

Google API Services User Data Policy

Ren's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke Ren's access at any time at myaccount.google.com/permissions, and can delete Ren's local token files.
